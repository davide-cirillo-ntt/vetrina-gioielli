Entra nel tuo negozio

Per pubblicare un gioiello serve un codice di accesso di GitHub. Si crea una volta sola e resta salvato su questo telefono.

Come si crea il codice — un minuto
  1. Apri questa pagina di GitHub.
  2. Dai un nome qualsiasi, per esempio Dashboard gioielleria.
  3. Alla voce Repository access scegli Only select repositories e seleziona soltanto il sito.
  4. Alla voce Permissions, sotto Repository permissions, metti Contents su Read and write. Non serve altro.
  5. Premi Generate token, copia il codice e incollalo qui sotto.

Trattalo come una password: non condividerlo e non usarlo sul telefono o sul computer di altri.
